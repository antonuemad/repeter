# جاهزية تجربة العملاء بالدعوات — بدون نشر

آخر تحديث: 15 أكتوبر 2026. التجربة الحالية لاختبار الدخول والربط وتجهيز المحتوى. صاحب المشروع
منع نشر أي محتوى على أي حساب طوال فترة الاختبار، بما في ذلك الخاص وغير المدرج والتجريبي.
هذا المنع مقدّم على أي خطوات نشر في أدلة الإطلاق القديمة. راجع [تعليمات المستودع](../../AGENTS.md).

## القرار الحالي

يمكن تجهيز تجربة مُدارة لعملاء محددين بالدعوات، ضمن المنصات والحسابات المصرح بها. لا يجوز
تقديمها كتجربة نشر فعلي أو خدمة إطلاق تجاري مكتملة. إضافة عميل داخل Repeater لا تضيفه
تلقائيًا إلى مختبري Google أو أدوار تطبيق Meta؛ هذه الموافقات مستقلة وتحتاج تجهيزًا لكل عميل.

| المجال | الحالة المثبتة | حدود الدليل والخطوة التالية |
|---|---|---|
| الدعوات وتعيين كلمة المرور | منفّذة؛ روابط أحادية الاستخدام ينسخها المدير يدويًا | العميل يختار كلمة مروره ويقبل النصوص بنفسه؛ لا بريد تلقائي |
| الاستعادة | طلب عام لا يكشف وجود الحساب، تحقق هوية وإعادة مصادقة المدير، ثم رابط مؤقت | تسليم الرابط والتحقق من الهوية عبر قناة موثوقة مسؤولية المدير |
| YouTube | حساب واحد مرتبط فعليًا | لا نشر فعلي، ولا اختبار استيراد أو قبول نشر على بيانات عميل |
| Facebook وInstagram | 95 صفحة و51 حسابًا مرتبطين بتفويض صاحب الحساب | تطبيق Meta غير منشور؛ ربط هذه الحسابات لا يثبت Advanced Access لكل العملاء |
| Google Drive | حساب واحد مرتبط فعليًا بصلاحية القراءة والتنزيل | لم نفتح ملفات العميل أو نستوردها كاختبار؛ استيراد المجلد وتجهيز فيديو اختُبرا بمحاكاة HTTP ووسائط مولّدة محليًا |
| TikTok | مؤجّل صراحة باختيار المستخدم بعد عدم وصول كود تسجيل المطوّر | لا مفاتيح مخترعة ولا ادعاء بوجود ربط؛ محاكاة الربط والرفض وحظر النشر موجودة |
| قفل النشر | النشر معطّل افتراضيًا، والحظر فعّال في web وworker | لا يمكن لقاعدة حساب أو زر نشر تجاوز `REPEATER_PUBLISHING_ENABLED=false` |
| النسخ الخارجي | Google Drive مستقل، تشفير ومجلد Repeater، نسخ قاعدة ومزامنة وسائط | أحدث نسخ الربط أُعيدت قراءتها وفُحصت البصمة؛ مفاتيح فك التشفير خارج السيرفر |
| الاستعادة | نجح استرجاع نسخة صغيرة في PostgreSQL معزول بلا شبكة أو worker | الاختبار قبل ربط الحسابات؛ استعادة وسائط فعلية وحدود زمن التعافي غير مقاسة |
| المراقبة | فحص المضيف كل خمس دقائق للخدمات وHTTPS والنسخ والقرص والطابور | التنبيه عبر Telegram مؤجّل باختيار المستخدم؛ لا رصد مستقل لانقطاع المضيف كله |

## ضوابط التجربة

- الإبقاء على `REPEATER_PUBLISHING_ENABLED=false`؛ رفع الحظر يحتاج تعليمات صريحة بعد انتهاء
  فترة الاختبار. كل قواعد النشر الحالية متوقفة ومساحة العمل متوقفة أيضًا كحماية إضافية.
- اختبارات النشر والتفويض والاستيراد تستخدم حسابات وهمية وHTTP محاكى وقاعدة اختبار منفصلة.
  توليد ملف فيديو وترميزه محليًا لا يرسل محتوى إلى منصة، ولا تُزرع بيانات تجريبية في الإنتاج.
- الربط الحقيقي هو تفويض صاحب الحساب على شاشة المنصة. لا تطلب كلمات المرور أو OTP أو
  الأسرار في المحادثة، ولا توافق على صلاحيات بيانات العميل أو النصوص القانونية نيابة عنه.
- Drive يطلب `drive.readonly`: الصلاحية تشمل قراءة وتنزيل ملفات الحساب، بينما إعداد المصدر
  يحدد المجلد الذي يُستورد منه. لا توصف الصلاحية بأنها محصورة في مجلد واحد.
- قيود تطبيقات Google التجريبية وMeta غير المنشورة تبقى قائمة؛ لا تُقدّم دعمًا عامًا أو نشرًا
  مضمونًا عبر TikTok أو أي منصة لم تستكمل مراجعتها.

## قبول أول عميل في هذه الفترة

1. ينشئ مدير المنصة مساحة منفصلة ودعوة لصاحبها، ويسلّم الرابط عبر القناة المتفق عليها.
   لا يُستخدم حساب المدير المشترك، ولا تُنشأ حسابات عملاء وهمية على الإنتاج.
2. يحدد الفريق للعميل المنصات المتاحة والقيود. يُجهّز مختبر Google أو دور Meta المناسب
   بإذن صاحب الحساب قبل محاولة الربط؛ TikTok مؤجل حاليًا.
3. يختار العميل كلمة مروره ويقبل السياسة والشروط بنفسه. تُراجع صلاحية المساحة وعزلها
   عن بقية العملاء، ووسيلة التواصل مع الدعم وطريقة استعادة الوصول.
4. تُراجع الواجهة وخيارات المصدر والمكتبة. أي استيراد فعلي لاحق يقتصر على مجلد ومحتوى
   يختاره العميل؛ الاختبارات الحالية محاكاة فقط، ولا يُجرى نشر حتى لو كان خاصًا.
5. يشغّل المشغّل فحص الفترة التجريبية للمنصات المسموح بها، ويتحقق من قفل النشر والنسخ
   وحداثة المراقبة. لا تُعتبر النتيجة دليل قبول نشر أو موافقة منصة لعميل جديد.

```bash
cd /srv/repeater/app/deploy
sudo docker compose --env-file .env exec -T web python -m repeater.cli integration-status --testing --platform gdrive --platform youtube --platform instagram --platform facebook
```

وضع `--testing` لا يرسل تنبيهات ولا يجري طلبات API. يرفض النجاح عند غياب ربط مختار، أو
فتح النشر، أو غياب/تقادم أي إيصال نسخ محلي أو خارجي. الفحص الافتراضي يشمل TikTok ويُظهر
أنه غير مجهّز؛ اختياره خارج الفحص المحدد لا يخفي حالته في التقرير العام.

## المتبقي قبل توسيع التجربة أو الإطلاق

- إكمال TikTok حين يقرر المستخدم استئنافه، وموافقات المنصات للعملاء خارج فريق التطوير.
- مراقبة مستقلة خارج المضيف وقناة تنبيهات حين يطلبها المستخدم.
- استعادة وسائط حقيقية وقياس السعة والتزاحم وحدود التخزين والمصادر والحسابات لكل عميل،
  على بيئة مناسبة وبنطاق اختبار مصرح به؛ لا يوجد RTO/RPO أو حمل عميل مقاس حاليًا.
- دورة إزالة الأعضاء وإغلاق مساحة العميل، إدارة الجلسات، وتثبيت سلسلة البناء وفحص الاعتماديات.
- صفحة تعريف عامة ومواد مراجعة التطبيقات وشروط الدعم والباقات والفوترة قبل خدمة تجارية عامة.
- قبول النشر الفعلي يبقى غير منفّذ وممنوعًا في هذه الفترة؛ لا يحوّل نجاح CI أو المحاكاة إلى
  تصريح نشر. يُخطط له فقط بعد إنهاء الحظر صراحة.
