# YouTube fact sheet (agent + my verification, 2026-10-14)
- videos.insert: "Quota impact: 100 calls per day. 1 unit in the Video Uploads quota bucket" (LU 2026-10-08). Default: 100 search.list calls, 100 videos.insert calls, 10,000 units/day for other endpoints; reset midnight Pacific. History: until 2025-12-04 upload cost 1600 units; 2026-06-01 separate buckets.
- Quota increase: must pass compliance audit (Audit and Quota Extension Form): privacy policy URL, ToS, demo creds, screenshots, project numbers, per-endpoint justification; no SLA; anecdotes: weeks to months.
- VERIFIED BY ME: live videos.insert doc says "Videos uploaded from unverified API projects are not restricted to private viewing mode." (The 2020 revision note said the opposite; never formally retracted; third parties still report locks.) → plan: not a hard gate, but still do audit for quota.
- Max file 256GB; channel unverified (no phone) max 15 min; channel daily upload cap undisclosed, counted across app+API (error uploadLimitExceeded).
- Resumable upload: uploadType=resumable, chunks multiple of 256KB, 308 Resume Incomplete, session URI expires.
- OAuth scopes: youtube.upload, youtube.readonly, youtube, youtube.force-ssl → all Sensitive (not Restricted) → no CASA. Verification: brand verification, privacy policy on same domain, Search Console domain ownership, demo video, 3-5 business days (or 10). Unverified apps with sensitive scopes: 100 new users lifetime cap. Testing mode: ≤100 test users, refresh tokens expire 7 days. Production tokens: until revoked / 6 months unused / 100 tokens per client per account.
- Required Minimum Functionality for upload clients: user sets title (≤100), description (≤5000 bytes), privacyStatus; multi-platform posters must let users select/deselect platforms.
- Shorts: vertical/square ≤3 min (since Oct 15 2024) → auto-classified; no API flag; max 1080p. Title ≤100, desc ≤5000 bytes, tags ≤500 chars. selfDeclaredMadeForKids on insert; notifySubscribers default true (set false for bulk). containsSyntheticMedia flag.
- Import own: NO download endpoint; Developer Policies forbid clients to "download, import, backup, cache, or store copies of YouTube audiovisual content without YouTube's prior written approval". Studio download: 720p/360p, 5/video/24h; Takeout for all. Data Portability API scopes dataportability.youtube.public_videos (Sensitive) etc. yt-dlp: PO tokens required, "Sign in to confirm you're not a bot" common on datacenter IPs → cookies.
- Listing: channels.list mine=true (1 unit) → relatedPlaylists.uploads → playlistItems.list (1 unit, 50/page). search.list forMine in 100/day bucket, indexing delays → use playlistItems.
- Specs: MP4, moov front, AAC-LC 48kHz stereo 384kbps, H.264 High, closed GOP half fps, 4:2:0, 1080p 8Mbps (24-30fps)/12Mbps (48-60).
- Changes: 2025-12-04 upload cost cut; 2026-06-01 buckets; 2026-07-07 brandPartner; 2026-09-14 thumbnails 50MB; 2026-05/06 derived metrics/data storage policies.
