# Instagram fact sheet (agent, 2026-10-14). Graph API v26.0 (Jul 29 2026).
- Two setups: (A) Instagram API with Instagram Login: pro account, no Page needed, graph.instagram.com, scopes instagram_business_basic + instagram_business_content_publish (+ _manage_insights). Web only. (B) Instagram API with Facebook Login: pro IG linked to a Page, graph.facebook.com, instagram_basic + instagram_content_publish + pages_read_engagement + pages_show_list. App can use one or the other, not both.
- Standard Access = only own/app-role accounts; third-party creators need Advanced Access → App Review + Business Verification. Review needs icon, privacy policy, business email, screencast per permission, ≥1 successful call per permission within 30 days; decision "within a week". Data Deletion callback URL (signed_request HMAC-SHA256, return {url, confirmation_code}) or instructions URL.
- Reels flow: POST /{ig-user-id}/media media_type=REELS video_url (public HTTPS, cURLed; any host) → poll GET /{container}?fields=status_code (EXPIRED/ERROR/FINISHED/IN_PROGRESS/PUBLISHED; poll once/min ≤5 min) → POST /{ig-user-id}/media_publish creation_id. Resumable upload also exists (upload_type=resumable + rupload.facebook.com/ig-api-upload) but Facebook-Login apps only.
- Params: share_to_feed, cover_url (JPEG ≤8MB), thumb_offset, audio_name, collaborators (≤3), location_id, user_tags, trial_params, is_ai_generated. Caption ≤2200 chars, 30 hashtags, 20 @tags.
- Limits: content_publishing_limit — guide says 100 posts/24h, references say 50; read GET /{ig-user-id}/content_publishing_limit at runtime. Containers expire 24h; ≤400 containers/24h. BUC rate: 4800 × impressions per 24h, error 80002.
- Specs: MP4/MOV, moov front, H.264/HEVC, 4:2:0, AAC ≤48kHz 128kbps, 23-60fps, max width 1920, aspect 0.01:1–10:1 (9:16 recommended), ≤25Mbps, 3s–15min, ≤300MB (third parties say 1GB).
- Import own media: GET /{ig-user-id}/media?fields=id,media_type,media_product_type,media_url,thumbnail_url,permalink,timestamp,caption (max 10K recent, since/until). media_url omitted if copyrighted/flagged audio (licensed music reels may have no URL). URL is signed CDN, expires (undocumented). No webhook for own new posts → polling.
- Tokens: IG Login: short 1h → long 60d (ig_exchange_token), refresh (≥24h old) another 60d. FB Login: user long-lived ~60d, Page tokens from long-lived user token do not expire.
- Changes: Basic Display API dead Dec 4 2024; IG Login content publishing since Jul 2024; impressions/plays → views (2025); Trial Reels Dec 2025; is_ai_generated Jun 2026; Instagram Audio API Jun 2026.
