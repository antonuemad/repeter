# TikTok fact sheet (agent, 2026-10-14)
- Direct Post: POST /v2/post/publish/video/init/ scope video.publish. Upload(inbox draft): /v2/post/publish/inbox/video/init/ scope video.upload (user must finish in app).
- FILE_UPLOAD: chunk 5-64MB (last up to 128MB), <5MB single chunk, >64MB must chunk, max 1000 chunks, max 4GB, upload_url valid 1h. PULL_FROM_URL: needs verified Domain (DNS record) or URL-prefix property; HTTPS, no redirects, reachable 1h; else 403 url_ownership_unverified.
- Duration: API accepts up to 10 min; respect creator_info max_video_post_duration_sec (3/5/10 min).
- post_info: privacy_level required and must match creator_info privacy_level_options; title ≤2200 UTF-16; disable_duet/stitch/comment; video_cover_timestamp_ms; brand_content_toggle/brand_organic_toggle; is_aigc.
- creator_info query required when rendering post page; 20 req/min.
- Unaudited: all content private (SELF_ONLY), max 5 users posting per 24h, 403 unaudited_client_can_only_post_to_private_accounts. Per-creator daily cap ~15 posts/day.
- Review: demo video(s) of full flow (≤5, 50MB each), privacy+ToS visible, production website, sandbox demo; several days to two weeks; sandbox no public posting.
- UX guidelines: title editable, privacy dropdown without default, toggles off by default, commercial content toggles, consent text "Music Usage Confirmation", preview + nickname, no promotional watermarks.
- Rate: init 6 req/min per user token; status fetch 30 req/min; Upload 5 pending/24h; errors spam_risk_too_many_posts, reached_active_user_cap. Status states PROCESSING_UPLOAD/DOWNLOAD, SEND_TO_USER_INBOX, PUBLISH_COMPLETE, FAILED. Webhooks: video.publish.completed, video.upload.failed, authorization.removed.
- Display API video.list: public videos only, max 20/page, fields incl. share_url, embed, cover (6h TTL) — NO file/play URL. Research API: academics only. Data Portability API: download link for posts but EEA/UK users only, approval 3-4 weeks.
- yt-dlp: supports @user profiles; play_addr non-watermarked; breakages 2026 (issue #17604 open since Sep 2026); IP-region affects formats; ToS §3.4 forbids scraping; dev guidelines ban watermark removal without consent.
- Specs: MP4/WebM/MOV; H.264/H.265/VP8/VP9; 23-60fps; 360-4096px; ≤4GB; ≤10min.
- OAuth: access 24h, refresh 365d, revoke endpoint. Scopes video.upload, video.publish, video.list, user.info.basic.
- 2025-26: photo posting, is_aigc; no API pricing; USDS JV Jan 2026; originality enforcement Sep 2025 (unofficial reports).
