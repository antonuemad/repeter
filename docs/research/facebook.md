# Facebook fact sheet (agent, 2026-10-14). Graph v26.0.
- Reels: POST /{page-id}/video_reels upload_phase=start → video_id + upload_url; POST rupload.facebook.com/video-upload/{video-id} with Authorization: OAuth, offset/file_size (binary) OR file_url header (hosted; http/https, no auth, robots must allow facebookexternalhit, no fbcdn URLs); then upload_phase=finish with video_state DRAFT|SCHEDULED|PUBLISHED, description, title, scheduled_publish_time (>10 min, ≤29 days).
- Status: GET /{video-id}?fields=status → video_status (error|expired|processing|ready|uploading|upload_failed|upload_complete), uploading_phase, processing_phase, publishing_phase{publish_status}. Copyright check on upload.
- Permissions for Reels: pages_show_list, pages_read_engagement, pages_manage_posts; Page token from user with CREATE_CONTENT task. publish_video not needed for Reels (it's for live video + crossposting).
- Reels limit: 30 API-published reels per Page per 24h. Only Public privacy. Errors 613 rate, 368 abusive, 6000 upload.
- Regular videos: Resumable Upload API (POST /{app-id}/uploads → POST /upload:SESSION → handle) then POST graph-video.facebook.com/{page-id}/videos with fbuploader_video_file_chunk; or file_url; scheduled_publish_time 10 min–6 months; published=false. Size numbers: error codes say max 2GB/40min (dated).
- Reels specs: MP4; H.264/H.265 (VP9/AV1 ok); 9:16 (ratio must be between 16:9 and 9:16); 1080x1920 recommended, min 540x960; 24-60fps fixed; duration 3–90s per API guide (June 2025 product announcement said "no length restrictions" for Reels on FB, docs still 3-90s → verify); closed GOP 2-5s; AAC-LC 48kHz stereo ≥128kbps.
- Access: Standard = app-role users only; Advanced Access needs Business Verification (since Feb 2023) + App Review per permission; screencast per permission (logged-out start, login, page select, publish, view), decision ~within a week. Dev mode: role users only.
- Rate: BUC 4800 × engaged users / 24h (type pages), header X-Business-Use-Case-Usage, error 80001. App-level 200 × users/hour.
- Import own videos: GET /{page-id}/videos ; Video node `source` = "URL to the raw, playable video file" (no documented expiry); GET /{page-id}/video_reels lists reels (since/until). Webhooks: Page `feed` (item video, verbs add/edit/delete) needs pages_manage_metadata + pages_show_list, subscribe via POST /{page-id}/subscribed_apps; `videos` field = encoding status.
- Tokens: user long-lived ~60d; Page tokens from long-lived user token do not expire (invalidated on role change/password/etc.); data access expires after 90 days of inactivity → reauthorize. System user tokens only for own business.
- Changes: v26.0 Jul 2026; v25 Feb 2026 (video insights metrics deprecated; webhook mTLS CA change Mar 2026); v24 Oct 2025 (video feeds ad placement ended). IG→FB crosspost: no API param (share_to_feed only). Page→Page crossposting needs publish_video.
